# Remvu：让下一个 AI 接着做

换一个 coding agent，项目最容易丢掉的是代码之外的信息：用户为什么坚持某个接口，哪条路线已经试过，某个“通过”是否真的运行了测试。

Remvu 把这些信息写进一个可随代码交接的 `REMVU.md`。接收方先读简短摘要，再查看决策、依据和未完成事项，不需要安装 Remvu 或翻原聊天。

它把用户确认、工具观察、agent 推断和待核实内容分开记录。旧决定被替代后仍保留历史；代码发生变化时，接收方能发现记忆对应的是旧状态。并发更新会检查版本，不会静默覆盖另一位 agent 的内容。

本地完整记忆和事件放在忽略的 `.remvu/`。Claude Code 和 Codex 适配器通过生命周期 hooks 记录可观察事件，再由当前 agent 利用已有上下文整理。脚本不额外调用模型 API；记录和阅读本身仍占用上下文。

公开分享需要主动调用 `/remvu share` 或 `$remvu share`。输出只有一个可读文件，公开证据随内容一起带走，私人原始记录留在本地。文件生成后不会自动上传。

Remvu 0.2 是候选版本，开放格式与参考实现一起发布。真实客户端验证、模拟测试和待完成项目均在[验证报告](validation-report.md)中列明。没有对照实测时，项目不会给出 token 节省比例。
