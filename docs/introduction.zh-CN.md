# 把 AI 任务交给下一个 agent

一次任务做完，真正难交接的往往是过程：改了哪些文件，哪条测试通过了，某个决定有什么依据，还有什么没做完。把整段聊天塞给下一个 agent，记录虽然多，找答案却要重新翻一遍。

Agent Task Export 把这些内容整理成一个本地记录包。接手的 agent 先读简短的交接摘要；需要核实时，再按编号取出对应的工具调用、返回值或补丁。长输出保留在单独文件里，重复内容只存一份。

它适合任务复盘、切换模型、跨聊天交接，以及保留一份可查的执行记录。当前支持 Codex 本地日志、部分命令行 JSON 事件和通用证据格式；其他来源需要先做格式转换。

脚本不调用模型 API，也不上传记录。摘要由当前 agent 根据已有上下文写出，明确区分已验证的结果和待办事项。导出器会列出缺少返回值的调用、无法解析的日志和不支持的内容，避免让接手者把记录缺口当成“已经完成”。

这里的决策摘要概括可以说明的依据。隐藏思考链、分析通道和系统指令不会导出；源日志本来没有留下的内容，也无法事后恢复。Git 快照能展示文件状态和差异，但不能证明每一处修改都来自这个任务。

节省上下文的方式很直接：先读摘要，需要时才读证据。脚本本身没有模型调用费用，实际 token 消耗仍取决于模型和读取内容。项目没有宣称固定的节省比例。

导出包包含常见凭据的自动脱敏，分享前仍要检查。仓库提供 skill、Python 脚本、测试和合成示例，可以从示例跑起，再用于真实任务。
